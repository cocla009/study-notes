# 🚀 全栈 ISP / 计算摄影工程师：一年期突围计划表

> **执行原则**：每天专注 1 小时，死磕 C++ 与底层逻辑。
> **战略目标**：打造极客级工程能力。进可作为冲刺东北大学（人工智能/机器人等方向）研究生复试的硬核背书，退可作为直接斩获大厂底层视觉算法 Offer 的杀手锏。

---

## 🟩 阶段一：重塑底层直觉 —— 传统 ISP 与数字信号处理（第 1-3 个月）
**核心目标**：脱离调包舒适区，理解光信号转化为数字图像的本质。

### 第 1 个月：拆解成像原理与 RAW 图解析

- [ ] 学习光线传播、CMOS 传感器工作原理及 Bayer 阵列结构。
- [ ] 配置纯 C++ 开发环境（禁用 OpenCV 高级图像处理函数）。
- [ ] **实操**：手写 C++ 代码读取 RAW 格式图像数据。
- [ ] **实操**：用纯 C++ 实现双线性插值（Bilinear）去马赛克（Demosaicing），将 RAW 转为 RGB。

### 第 2 个月：打磨传统滤波器与信号处理

- [ ] 复习微积分与数字信号处理基础，理解空域（Spatial Domain）与频域（Frequency Domain）。
- [ ] **实操**：用 C++ 手写实现高斯滤波（Gaussian Filter）。
- [ ] **实操**：用 C++ 手写实现双边滤波（Bilateral Filter，掌握保边去噪核心逻辑）。
- [ ] 对比手写滤波器与现成库函数的性能与效果差异。

### 第 3 个月：色彩空间与基础增强
- [ ] 学习不同的色彩空间理论（RGB, YUV, HSV 等）。
- [ ] **实操**：用 C++ 实现 RGB 与 YUV / HSV 的互相转换算子。
- [ ] **实操**：用 C++ 实现图像直方图统计与直方图均衡化（Histogram Equalization）。

---

## 🟦 阶段二：接管物理世界 —— 3A 算法与多视角几何（第 4-6 个月）

**核心目标**：将高等数学理论转化为对物理硬件和光学的代码控制。

### 第 4 个月：自动对焦（AF）与微积分实战

- [ ] 学习图像梯度概念及常用的边缘检测算子（Sobel, Laplacian）。
- [ ] 结合微积分中的导数知识，理解清晰度评价函数的数学本质。
- [ ] **实操**：用 C++ 编写一套基于图像梯度的清晰度评价算法。

### 第 5 个月：自动曝光（AE）与自动白平衡（AWB）
- [ ] 学习“灰度世界法”（Gray World）和“完美反射法”等白平衡理论。
- [ ] 理解 PID 控制原理。
- [ ] **实操**：接入 USB 摄像头，用 C++ 代码尝试接管视频流，写一个简单的控制逻辑动态调节亮度和色温。

### 第 6 个月：投影几何与空间变换初探
- [ ] 学习针孔相机模型，理解相机内参（Intrinsic）与外参（Extrinsic）。
- [ ] 学习对极几何（Epipolar Geometry）与单应性矩阵（Homography）。
- [ ] **实操**：用 C++（可借助 OpenCV 基础矩阵运算）进行一次简单的相机标定或图像透视变换。

---

## 🟧 阶段三：AI 降维打击 —— 从高层语义到像素级增强（第 7-9 个月）
**核心目标**：引入深度学习魔法，攻克全英文文献，掌握前沿画质提升方案。

### 第 7 个月：跑通经典 AI 画质增强模型
- [ ] 研究经典图像去噪网络（如 DnCNN）或超分辨率网络（如 ESPCN, FSRCNN）。
- [ ] 理解深度学习在 Low-level Vision 任务中如何替代传统算法。
- [ ] **实操**：使用 Python/PyTorch 跑通一个开源的图像增强模型，完成训练和验证。

### 第 8 个月：前沿架构跟进与文献阅读
- [ ] 了解 Transformer 和 GAN 在去雾、去模糊及暗光增强中的应用。
- [ ] **实操**：精读 1-2 篇 CVPR / ECCV 级别的纯英文顶会论文（重点看 Abstract, Method, Experiments）。
- [ ] 整理论文中的创新点和网络架构图。

### 第 9 个月：视频时序处理机制
- [ ] 从单帧图像思维切换到视频流思维。
- [ ] 了解光流（Optical Flow）概念。
- [ ] 学习视频去噪（V-Denoising）中如何利用多帧的时间相关性（Temporal Consistency）。

## 🟥 阶段四：榨干硬件算力 —— C++ 与 TensorRT 极限部署（第 10-12 个月）
**核心目标**：打造工业界最看重的核心壁垒——端侧高性能部署。

### 第 10 个月：ONNX 转换与 TensorRT 预研
- [ ] 学习 PyTorch 模型到 ONNX 格式的导出规范。
- [ ] 阅读 NVIDIA 官方全英文 TensorRT 文档。
- [ ] **实操**：将第 7 个月跑通的 PyTorch 图像增强模型成功导出为 ONNX 文件。

### 第 11 个月：纯 C++ 推理引擎构建
- [ ] 学习 TensorRT C++ API 的基本调用流程（Builder, Network, Engine, Context）。
- [ ] **实操**：抛弃 Python，编写纯 C++ 代码解析 ONNX 模型并构建 TensorRT Engine。
- [ ] **实操**：编写 C++ 推理代码，读取本地图片进行 AI 增强处理，并输出结果。

### 第 12 个月：极限加速与项目闭环

- [ ] 学习 FP16 与 INT8 量化（Quantization）技术。
- [ ] 学习 CUDA 显存与 CPU 内存之间的数据拷贝优化（Pinned Memory 等）。
- [ ] **实操**：对 TensorRT 引擎进行量化加速，将处理速度（FPS）推向极限。
- [ ] **实操**：整理所有代码，编写详尽的 README 文档（包含架构图、FPS 对比、处理前后效果图），上传 GitHub，完成最终开源项目交付。
