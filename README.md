### 📅 第 1–2 周：Python 高级编程 + 工程基础（增强版）

**为什么增强？**  
未来 AI 工程不再是写模型，而是构建 *可维护、可扩展、可协同的系统*。

#### ✅ 学习内容

- Python 进阶：装饰器、上下文管理器、生成器、异常体系、类型提示（typing）
- Shell 脚本：自动化训练/部署脚本
- Git & Git Flow 分支规范、Commit 规范（推荐 Conventional Commits）
- Linux：`grep`、`awk`、`sed`、`tmux`、`scp`、`htop`
- **增强**：  
  - 日志系统设计（结构化日志 & 隐私日志规范）  
  - 配置管理（YAML + argparse + dotenv）  
  - 项目结构标准化（符合开源标准）

> 💡TIP：从“写脚本”升级为“写工具”。你写的脚本要能复用、扩展、给别人用。

#### 🧪 实践任务

编写一个可复用的 `log_toolkit`，支持：

- 多级别日志（INFO/WARN/ERROR）  
- 本地/云日志输出  
- 自动脱敏（隐私信息 masking） ← *未来安全合规必备*  
- Shell 一键初始化项目模板

### 📅 第 3–5 周：PyTorch 深度学习核心（增强版）

**新增重点**：未来不会训练模型的人会被淘汰，会训练但不懂系统的人也会被淘汰。  

学习要兼顾 **效率 + 可解释性 + 工程化**。

#### ✅ 学习内容

- Autograd、DataLoader、模型训练/评估流程
- 优化器、LR Scheduler、Early Stopping、Checkpoint
- 可解释性入门：Grad-CAM、Attention 可视化（未来要求变“会调模型”成“能解释模型”）
- **增强**：
  - AMP（自动混合精度）
  - DDP（分布式训练基础）
  - **模型鲁棒性意识**：简单对抗扰动体验（非研究，做认知）

#### 🧪 实践任务

- 自建 `Trainer` 与 `Evaluator` 类（具备 resume、metrics、日志记录能力）
- 训练一个轻量化 CNN，在 CIFAR-10 达到 >85% 准确率
- 可视化训练曲线 + Grad-CAM 热力图

### 📅 第 6–7 周：计算机视觉（CV）基础（增强版）

> 增强方向：隐私保护、数据标注规范、机器人视觉基础感知

> NOTE：未来大量模型会直接部署在端侧相机、机器人、工业设备上，需建立软硬结合认知。


#### 🧪 实践任务

### 🔹 第 1–3 周：CLIP 与多模态检索系统（增强版）

> 新增：文本偏差检测、多模态安全、嵌入空间对齐理解

#### ✅ 学习内容

- CLIP 原理：对比学习、InfoNCE Loss、图文共同嵌入空间
- Zero-shot 分类、多标签检索、图文相似度（cosine）
- 特征可视化 & 嵌入空间分布分析（t-SNE/Umap）
- **增强内容：**
  - 图像/Text embedding 偏差与鲁棒性分析
  - “看图说错话”风险评估（多模态安全必修）
  - 小型自建图文数据集 → CLIP 再训练或 LoRA 微调

#### 🧪 实践任务

- 构建 500 ~ 2000 条图文数据的小型 embedding 库
- 实现**以文搜图**与**以图搜图**检索 Demo
- 输入不同风格文本描述，分析 embedding 偏差与鲁棒性

#### 🚀 阶段项目 ①：**NicheLook — 小众风格视觉搜索引擎**

目标：突破“商品检索只看大类目”的传统做法。  
用户输入如：“日系森系文青风外套” → 返回相似商品图。

> ✅ **增强要求**：增加“检索解释能力” → 返回匹配原因（模态可解释性）

### 🔹 第 4–6 周：BLIP / BLIP-2 与多模态生成（增强版）

- LoRA 微调 BLIP-2，构建自定义视觉问答能力
- **增强内容：**
  - 图像→文本生成幻觉诊断 & 对齐改进技巧
  - 指令数据构建：`<image>` + 问题 + 答案 + 解释
  - 多模态事实性验证（MM-SFT 前置概念）

#### 🧪 实践任务

- 输出回答 + 置信度 + 视觉依据（Explainability）

#### 🚀 阶段项目 ②：**ProductQA — 电商商品图智能问答助手（增强版）**

> Q: “这件衣服适合夏天穿吗？”

| 阶段 | 能力要求 | 任务类型 | 达成标准 |
|--------|----------------|---------------------|----------------|
| Lv1：跑通 | 能跑通官方代码与训练流程 | 跟随官方repo | 结果与论文误差 ≤3% |
| Lv2：复现 | 能在不同数据/环境下复现效果 | 改数据、改框架、改模型实现 | 能解释误差来源 |

> ✅ **科研入门最低门槛：达到 Lv3**  
> 📍 **能写论文：Lv4**

### 🧬 A.5.2 实验方法论（避免“玄学调参”）

科研实验应基于科学方法，而非“碰运气”。以下为核心原则：

#### **📍 控制变量法（Control Variables）**

一次实验只能改一个变量：

- 不能多超参一起改（否则无法归因）
- 建议每次实验保留完整日志与超参记录

#### **📍 消融实验（Ablation Study）设计模板**

消融不是“删组件看看下降”，而是为证明你提出的组件确实带来贡献。

标准消融结构：

| 模型版本 | 改动 | 指标变化 | 结论 |
|------------|----------------|--------------|----------------|
| Baseline | - | 基准 | - |
| Ours – X | 移除组件X | ↓5.2% | 证明X有效 |
| Ours – Y | 移除组件Y | ↓2.1% | 证明Y有效 |
| Ours | 全部模块 | 最优 | 模块互补性强 |

记住：  
> ❌ 只做完整模型 vs baseline 不叫消融  
> ✅ 要逐点证明贡献来源

#### **📍 指标选择与统计显著性**

至少包含：

- 平均值 + 标准差（多个seed运行）
- t-test 或 Wilcoxon test（简单版本即可）

> 若实验仅跑1次，属于“不严谨实验”。

### 🧪 A.5.3 论文复现实践建议（按难度递增）

| 难度 | 论文方向 | 推荐原因 |

## A.6 🧠 如何完成自己的第一篇论文（从复现→改进→创新）

> 这是科研路线的核心价值所在  
> 本节提供**可照做的三阶段路线**，从“复现者”成长为“作者”

### 🎯 阶段目标概览

| 阶段 | 目标 | 时间 | 输出 |
|--------|------------------------------|--------|----------------|
| Phase 1 | 复现 + 深度理解论文 | 4–6周 | 复现报告、复现代码 |
| Phase 2 | 改进已有方法（小创新） | 4–6周 | Ablation + 改进版实验 |
| Phase 3 | 完成自己的论文（新方法） | 8–12周 | 可投稿论文草稿 |

---

### 🧩 Phase 1：复现与理解（4–6 周）

关键输出：

- 完整跑通论文，误差 ≤3%
- 自己重写（不是复制）论文思维导图
- 自己撰写“论文讲解版”笔记（可供别人看懂）

建议选择论文：**CLIP, BLIP-2, MAE, LLaVA, RT-2**（任选其一）

---

### 🔧 Phase 2：小幅改进与验证（4–6 周）

目标：**从“跑通”升级为“我能做得更好”**

常用改进方向（非常实用，容易发Workshop/CCF C）：

| 改进类型 | 示例 |
|----------------|----------------------------|
| Loss改进 | Alignment loss、Uniformity loss 组合、权重变化 |
| 数据策略 | 数据过滤、更难负样本、合成数据、提示增强 |
| 模块结构 | 替换Attention、引入Cross-Attention、轻量模块 |
| 训练策略 | 更优LR策略、warm-up、SWA、SAM |

成果要求：

- 至少找到 **1 个有效提升点**
- 提供实验对照 + 消融 + 误差分析
- 输出小论文（2–4页）或技术博客

---

### 🚀 Phase 3：创新与论文撰写（8–12 周）

目标：做出**属于你自己的方法**。

常见创新来源（务必收藏）：

| 创新入口 | 如何找到创新点 |
|------------------|---------------------|
| 现论文弱点 | “作者没解决的是什么？” |
| 跨领域嫁接 | NLP方法 → CV；CV方法 → Robotics |
| 数据分布差异 | “换数据会崩吗？能做适配吗？” |
| 降本提效 | 用更低算力取得相似效果 |
| 新场景 | 多模态用于机器人执行与决策 |

## A.7 🧪 多模态 × 具身智能方向科研选题建议（理论+算法向）

| 方向 | 示例选题（可直接立项） |

### 🟩 Level 2：中等创新（有潜力发 CCF B/主流会议短文）

周期：4–8 个月  
目标：模型或算法层面的“可验证提升”研究

方向建议：

| 研究方向 | 为什么有潜力 |
|----------------------------|---------------------------|

> 🔥 这类研究极受研究院关注，适合作为研究生或博士申请材料

周期：9–18+ 个月
